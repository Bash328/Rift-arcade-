# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite + TypeScript, Colyseus (multiplayer server), Three.js (game rendering). Hub and page chrome are plain HTML/CSS, no UI framework. (Inferred from the repo; the user asked for a vanilla approach.)

## Users

Players who open Rift Arcade on desktop or phone, usually with friends, and want to jump into a short online multiplayer game with no download or account.

## Product Purpose

Rift Arcade is a website hosting a growing collection of 3D online multiplayer browser games. The landing page is a hub where each game is presented as an arcade cabinet. Success: a visitor picks a game and is playing within seconds.

## Capabilities and Constraints

- One game today: Cube Tag (1-8 players, online, 60-second rounds, highest survival score wins). More games are planned; none are named or dated, so the hub must not invent titles or release claims.
- Games run in the browser; no accounts exist yet.
- Must be usable on mobile as well as desktop.

## Brand Commitments

- Name: Rift Arcade.
- Neon synthwave arcade look, user-specified palette: cyan #00e5ff, pink #ff2bd6, deep purple #120826.
- Games are shown arcade style, with a cabinet-style frame around the game screen on game pages.

## Evidence on Hand

No testimonials, player counts, or press. Do not fabricate any.

## Product Principles

- Get the visitor into a game in one click.
- Every game lives in the same arcade world: new cabinets slot into the hub without redesign.
- Honest about what exists: unreleased games are shown as "coming soon", never described.
